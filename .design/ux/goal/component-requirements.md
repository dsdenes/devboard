# Goal mode — component requirements

Catalog read first: `openui.json` (Button, IconButton, Input) and
`.devboard/.storybook/main.ts` + `stories/design-system.stories.ts` (one overview story). No
existing component carries a page identity block or a lifecycle position, so two components are
new; everything else composes the shipped primitives.

| Need | Decision | OpenUI entry | Storybook story | Data/state requirements | Accessibility | Token needs |
|---|---|---|---|---|---|---|
| Page identity on all six Goal pages: eyebrow, title, optional subtitle, meta line, action group | **New** `PageHeader.svelte` | New `PageHeader` | New `Design System/PageHeader`: default, long-title, many-actions, narrow | Long titles wrap once then truncate; 0–4 actions; optional meta with live region left to the page | `header` landmark per page; one `h1`; actions keep their own labels; no focus management inside | `page-title`, `body-small`, `label`, `accent`; 8px/12px gaps; 4px radius; no new tokens |
| Lifecycle position: five stages, current stage, pause, pass, work item | **New** `StageTrack.svelte` | New `StageTrack` | New `Design System/StageTrack`: not-started, running, paused, finished, long work label | `stage` ∈ goal/epic/adr/implementation/finished; `paused`; `pass` number; optional work label + URL; never infer a stage the server did not send | `ol` with `aria-current="step"`; paused and finished are words, not color; work link has its own name and opens in a new tab | `accent`, `success`, `warning`, `border`, `surface`, `muted-foreground`; 2px/4px/6px/8px gaps; 3px radius |
| Mode selection and app actions | **Modify** `ActivityBar.svelte` | Existing (no catalog entry; shell geometry) | Existing overview story unaffected; rail is exercised by `verify:interface` | Three modes; optional state dot with a spoken state; footer commands/notifications/theme; exactly three `role="tab"` | `tablist` contains only tabs; each tab has icon + visible label + `aria-controls`; footer buttons use `aria-label`/tooltip; state dot is `aria-hidden` with the state in the tab's accessible description | `activity-bar`, `secondary`, `accent`, `border`, `border-strong`, `muted-foreground`; 64px rail, 56×48px tabs, 28px buttons |
| Sidebar navigation with progress, next record, pending records, lanes | **Compose** existing sidebar buttons/badges | Existing | — | 0/1/many records; 0/1/many lanes; missing skills; unsaved goal; long titles truncate at the group width; statuses use words | `nav` groups stay labelled; `aria-current` for the active page; the skills disclosure keeps `aria-expanded`/`aria-controls` | `sidebar`, `accent-surface`, `badge-*` |
| ADR list: scan, filter, start | **Modify** `AdrTable.svelte` | Existing table pattern (no catalog entry) | — | 0/1/8+/long title/long summary/no summary; all/pending/resolved; filter that empties the table; row action disabled with a reason; rows stay ≤28px | real `table`, column `scope`, rows focusable with Enter/Space, action is a real `button` inside the row, search field labelled | 12px table type, `border-subtle` row rules, `row-hover`, `mono-small` file |
| ADR detail identity and decision | **Compose** PageHeader + facts grid + Button | PageHeader/Button | PageHeader stories cover long title | pending/resolved; missing record; no summary; start disabled reason | `dl` for facts; heading level 2 for the decision label; start button has its own label | `kv` spacing 2px/10px, `mono` |
| Goal document editor, state, save/recreate/skills | **Compose** PageHeader + MonacoEditor + Button + textarea | PageHeader/Button/Input | PageHeader long-title story | empty goal, saved, unsaved, read-only during work, no operation, creation, revision, skills prep; long text; save failure (server error notice) | editor keeps its label; revision textarea labelled; Save is the primary; read-only state is spoken via the editor | existing `goal-document` layout: editor fills, revision ≥60px at the bottom |
| Skills list with selection and contradictions | **Compose** list buttons + Badge + PageHeader | PageHeader/Button | — | 0/1/5/20 skills; long names and descriptions; contradictions 0/1/many; selected; preparation in progress | list is a `ul`; rows are buttons with `aria-current`; contradiction text reads both directives | `mono` names, `body-small` descriptions, `warning`/`error` tones |
| Lane identity, status, attempt, question, activity | **Compose** PageHeader + facts + Terminal + choice list | PageHeader/Button | — | running/paused/closed/failed/retrying/parked; attempt 1/n; epic link or record; missing lane; question with 0 options; long activity lines | status is a word; choice buttons are buttons; answer form has a label; terminal is labelled | `choice-*`, terminal surface |
| Notices: error, upgrade, operation banners | **Compose** `.message` | Existing | — | one error, upgrade pending, stopped run, operation running | `role="alert"` only for errors; operation notices use `role="status"` | `error-surface`, `accent-surface`, `warning-surface` |
| Destructive reset | **Compose** details disclosure + Buttons | Existing `Button`/destructive | Existing button story | closed/armed/running/result; reason text; disabled when disconnected | native `details`/`summary`; confirm is destructive; status line announced | `error`, `destructive` |

## Catalog additions

`PageHeader` and `StageTrack` are declared in `openui.json` with the props that ship. `DESIGN.md`
gains the corresponding component entries in `## Components`. No token changes: both read existing
custom properties. `design/tokens.json` is regenerated and diffed to prove it is unchanged.
