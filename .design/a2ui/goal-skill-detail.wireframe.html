Differential Conformance Testing

Use the specification as the authority for format correctness and the reference implementation as the oracle for the compatibility contract.

  • Feed the same input, options, and operation sequence to both implementations.
  • Compare exactly: bytes, structure and value types, error category and failure point.
  • Retain every divergence as a regression case. Run with bun test.
