# Consistent naming

The fixture skill names every vocabulary violation category.

## Architectural violations

- **synonymous naming:** two words name one concept.
- **semantic ambiguity:** one word names two concepts.
- **inconsistent vocabulary:** the same concept changes word across modules.
- **misleading naming:** a name says something the code does not do.
- **unnecessary terminology:** a name invents a word the project never needs.
- **conceptual collision:** two concepts share one word.
- **implementation-driven naming:** a name mirrors a library instead of the domain.
